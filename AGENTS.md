# Upside agent notes

- Product name is **Upside** (UI, metadata, docs). Legacy `portfell_*` table names and `portfell-*` localStorage keys stay as-is so the shared book / Save lock don’t break.
- **Do not invent or “fix” Aasad holdings** unless Martin pastes a new sheet. Canonical Aasad: cash −7000; NBIS 500@109.96; CRWV 1100@83.27; RKLB 200@68.65; BMNR 1500@18.20; VST 200@145. No NVDA/AVGO on Aasad. (This is only a guardrail against hallucinating Martin's own real data — it is not a product-wide bias; see next point.)
- **Generic product direction (2026-08-12):** the app is moving toward being usable by people outside the family (friends, eventually strangers). Per-ticker "house" Call %/Stock-Target baselines and the forecast engine's hardcoded per-ticker price-target floors (old `CALL_PCT_BASELINES` / `STOCK_TARGET_BASELINES` / `TICKER_BASE_MULTS`) have been **removed on purpose** — Call % now comes purely from each ticker's own realized volatility (`src/lib/market/write-plan.ts`), and forecast paths are reasoned per-ticker by the model with only a modest, generic sector-shaped fallback (`src/lib/forecast-conviction.ts`) for gaps. Do **not** reintroduce ticker-specific hardcoded bias/targets — Martin's own investing opinions belong in his own conviction notes/thesis fields, not in code every user shares.
- Not financial advice: Margus/Thesis Pulse/Forecast are framed as educational/informational scenario tools, not personalized investment advice. Keep disclaimer language intact when touching those surfaces (see `src/lib/ai/disclaimer.ts` if present, or the relevant persona/prompt files).
- Market data and LLM calls run on free tiers with multi-provider fallback chains (see `src/lib/market/quotes.ts` and `src/lib/ai/model.ts`) so a single provider's rate limit doesn't take the app down — extend the chain rather than hard-depending on one provider.
- CSV import exists for onboarding holdings without a screenshot (`src/lib/csv-import.ts` / holdings import UI) — keep it working for people who aren't Martin's family.
- Respect `localStorage` key `portfell-locked` and `data/locked-demo.json`. Never delete the lock. Prefer asking Martin to hit **Save** rather than bumping `portfell-demo-v*` to force a reseed.
- Production data lives on the shared **Upthink Platform** Supabase project in `portfell_portfolios` / `portfell_holdings` (not a separate Supabase project).
- Auth: Google SSO + co-ownership (`portfell_portfolio_owners`). No sheet PIN/password; no guest share links — invite partners from My account.
- **Community membership is opt-in only — never auto-join anyone on sign-in.** `ensureProfileAndClaims` (`src/lib/auth/ensure-profile.ts`) used to silently add every new signed-in user to Upside Circle unconditionally; that leaked real users' books to each other and was removed in migration `030` (see `docs/AUTH_AND_COMMUNITIES.md`). Communities have a `visibility` column: `private` (default, invite-link only) or `public` (discoverable via `GET /api/communities/discover`, joinable only by requesting via `POST /api/communities/:id/join-request` and an admin approving via the same route's `PATCH`). Do not add any code path that inserts a `portfell_community_members` row without either an accepted invite or an admin-approved join request.
- Lab extras (conviction, cashflow, arena, badges) sync via `portfell_lab_state` **per owner**.
- Shared-book mutations require a signed-in **co-owner** only (optional demo Save lock `portfell-locked` is separate and local-only).
- Prefer `SUPABASE_SERVICE_ROLE_KEY` for API writes (with ownership checks in code). Nightly book snapshots: `portfell_book_snapshots` via `/api/cron/snapshot` (02:00 UTC).
- After every push/prod deploy: verify Vercel production SHA matches `git rev-parse HEAD` before telling Martin it’s live (see `.cursor/rules/vercel-live-matches-push.mdc`).
- No Milestones sheet in the seed.
- **Experience tier vs. options experience are two separate flags — do not blend them.** `experience_tier` (novice/investor/advanced, from onboarding Q1 blended with Q2) controls which *meta-tabs* are default-hidden (Lab, which now contains Pulse and Seasonality as sub-tabs), which Lab sub-tabs are hidden (`TIER_HIDDEN_LAB_TABS`, e.g. Risk for investor tier), and panel default-visibility. `knows_options` (`src/lib/experience-tier.ts`, tri-state: `null` = unanswered/legacy user, `true`/`false` = explicit) is answered directly by onboarding Q2 alone and independently controls a **hard removal** of every options/covered-call surface when `false` — CC panel forced invisible (not just default-off), strike alerts filtered out of `bookAlerts`, the Target-call% field hidden in `HoldingModal`/CSV import, and the options-only tool set (`setCallPct*`, `setStockTarget*`, `proposeWritePlan`/`applyWritePlan`) dropped entirely from Margus's chat tools + the CC glossary/strategy block stripped from his system prompt (`src/lib/ai/cc-advisor.ts`). A "very experienced" investor can validly have zero options experience — never derive one flag from the other.
