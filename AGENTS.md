# Upside Lab agent notes

- Product name is **Upside Lab** (UI, metadata, docs), served at `upsidelab.app`. Legacy `portfell_*` table names and `portfell-*` localStorage keys stay as-is so the shared book / Save lock don’t break.
- **Do not invent or “fix” Aasad holdings** unless Martin pastes a new sheet. Canonical Aasad: cash −7000; NBIS 500@109.96; CRWV 1100@83.27; RKLB 200@68.65; BMNR 1500@18.20; VST 200@145. No NVDA/AVGO on Aasad. (This is only a guardrail against hallucinating Martin's own real data — it is not a product-wide bias; see next point.)
- **Generic product direction (2026-08-12):** the app is moving toward being usable by people outside the family (friends, eventually strangers). Per-ticker "house" Call %/Stock-Target baselines and the forecast engine's hardcoded per-ticker price-target floors (old `CALL_PCT_BASELINES` / `STOCK_TARGET_BASELINES` / `TICKER_BASE_MULTS`) have been **removed on purpose** — Call % now comes purely from each ticker's own realized volatility (`src/lib/market/write-plan.ts`), and forecast paths are reasoned per-ticker by the model with only a modest, generic sector-shaped fallback (`src/lib/forecast-conviction.ts`) for gaps. Do **not** reintroduce ticker-specific hardcoded bias/targets — Martin's own investing opinions belong in his own conviction notes/thesis fields, not in code every user shares.
- Not financial advice: Margus/Thesis Pulse/Forecast are framed as educational/informational scenario tools, not personalized investment advice. Keep disclaimer language intact when touching those surfaces (the wording lives in `src/lib/disclaimer.ts`; personas and prompts are under `src/lib/ai/`).
- **No market slang in anything a person reads, and not in instructional prose sent to the model either.** A grandma should get every sentence. Never say sleeve, marks, tape, conviction, digestion, dry powder, beta, risk-on, drawdown, rotation. Say the plain thing (group of similar stocks, today's prices, why you own it). **Thesis is allowed** (Pulse badges: Thesis intact / Thesis watch / Thesis broken). Ban the rest in `MARGUS_PERSONA` and scrub leftovers in `humanizeMargusText`. Schema field names (`thesisStatus`, `convictionKey`) can stay. Ban lists may name the words.
- Market data and LLM calls run on free tiers with multi-provider fallback chains (see `src/lib/market/quotes.ts` and `src/lib/ai/model.ts`) so a single provider's rate limit doesn't take the app down — extend the chain rather than hard-depending on one provider.
- CSV import exists for onboarding holdings without a screenshot (`src/lib/csv-import.ts` / holdings import UI) — keep it working for people who aren't Martin's family.
- Respect `localStorage` key `portfell-locked` and `data/locked-demo.json`. Never delete the lock. Prefer asking Martin to hit **Save** rather than bumping `portfell-demo-v*` to force a reseed.
- Production data lives on a **dedicated Upside Lab Supabase project** (`uzrnybyggznpvgxgrvgl`, `portfell_*` tables). Isolation is URL + keys, not a table rename. The shared Upthink Platform project is not used by this app.
- Auth: Google SSO + co-ownership (`portfell_portfolio_owners`). No sheet PIN/password; no guest share links — invite partners from the sheet (Invite next to Add holding). Account is you, data, and the danger zone.
- **Community membership is opt-in only — never auto-join anyone on sign-in.** `ensureProfileAndClaims` (`src/lib/auth/ensure-profile.ts`) used to silently add every new signed-in user to Upside Circle unconditionally; that leaked real users' books to each other and was removed in migration `030` (see `docs/AUTH_AND_COMMUNITIES.md`). Communities have a `visibility` column: `private` (default, invite-link only) or `public` (discoverable via `GET /api/communities/discover`, joinable only by requesting via `POST /api/communities/:id/join-request` and an admin approving via the same route's `PATCH`). Do not add any code path that inserts a `portfell_community_members` row without either an accepted invite, an admin-approved join request, or household circle mirroring (`portfell_household_groups`: Martin/Amanda and Rasmus/Karoliine copy join/leave/role across the pair; classrooms stay per person). **Classroom** (`kind = classroom`, always private) is the high-school / uni paper class: invite redeem provisions one homework sheet with `starting_cash` and pins it. Teacher `class_plan` sets buy / closed / sell-and-move / open periods. Never share a real book into a class. Never auto-join a class on sign-in.
- **One scheduled email: the Sunday letter.** The weekday ("morning") and after-close notes were removed on purpose (2026-08-19) — routes, crons, copy, and the account/onboarding questions all went with them. `note_sunday` is the only preference; `note_morning` survives as an unused column. The letter lives in `src/lib/weekly-letter.ts` (sections, HTML, plain text) with `src/lib/weekly-margus.ts` writing the two human paragraphs on top, and it always ships even when the model is down (`fallbackWeeklyTake`). Its add/trim/sell suggestions come from Pulse verdicts the reader already saw (`portfell_lab_state.conviction` stamps) plus position-size arithmetic — never invented by the model. A Pulse "watch" verdict deliberately produces no suggestion. Email colors are the site's oklch tokens converted to hex in `EMAIL` (`src/lib/email-letter.ts`); if a token in `globals.css` moves, re-convert rather than eyeballing.
- Lab conviction notes sync via `portfell_lab_state` **per owner**, and so does the watchlist (`watchlist` column, migration `20260819140000_lab_watchlist.sql`) so the Sunday letter can suggest names the reader is watching. Arena, cashflow, badges, and journal were removed (no UI, no columns).
- Shared-book mutations require a signed-in **co-owner** only (optional demo Save lock `portfell-locked` is separate and local-only).

Encrypted cold copies + WAL backup verification: `/api/cron/disaster-recovery` (03:00 UTC), see `docs/DISASTER_RECOVERY.md`. Zero-downtime SQL: `docs/ZERO_DOWNTIME_MIGRATIONS.md` and `scripts/migrate-online.ts`.
- After every push/prod deploy: verify Vercel production SHA matches `git rev-parse HEAD` before telling Martin it’s live (see `.cursor/rules/vercel-live-matches-push.mdc`).
- No Milestones sheet in the seed.
- **Experience tier vs. options experience are two separate flags — do not blend them.** `experience_tier` (novice/investor/advanced, from onboarding Q1 blended with Q2) controls which *meta-tabs* are default-hidden (Lab, which contains Seasonality as a sub-tab; Pulse is top-level and shown to every tier on purpose), which Lab sub-tabs are hidden (`TIER_HIDDEN_LAB_TABS` — both tables are **empty for every tier** as of 2026-08-18 per a product call, so nothing is tier-hidden today; the machinery is live and one entry brings it back), and panel default-visibility. `knows_options` (`src/lib/experience-tier.ts`, tri-state: `null` = unanswered, `true`/`false` = explicit) is answered directly by onboarding Q2 alone. Use `shouldHideOptions()`: options/covered-call UI is hidden **only on an explicit `knows_options === false`** (CC panel, strike alerts, Call % fields, briefing pep talks, Margus options tools + glossary). Unanswered (`null`) **shows** it. This used to read "shown only when `true`", i.e. unanswered hid it too — that stricter rule was disabled outright on 2026-08-18 rather than shipped, and it cannot be restored as written: `shouldSkipExperienceOnboarding` skips the questionnaire as soon as `holdingsCount > 0`, so every existing holder's answer is permanently `null` and treating that as "hide" would strip covered calls from all of them at once, silently. The answer is changeable either way in Account. A "very experienced" investor can validly have zero options experience — never derive one flag from the other.
- **The bottom dock is one well, one cell per destination — do not build it around sheets.** `BookModeDock` draws the app sections, then one cell per portfolio you own, then Circle, all as the same `7.5rem` cell in one floating `.glass` card. **The bar has no band behind it** — the `nav` is a `pointer-events-none` centring container and nothing else, so the dock floats over the page the way Arena's does; a full-width veil there drew a horizon line across the ambient field and duplicated glass the card already carries. Anything full-width and transparent over content needs `pointer-events-none`, or it swallows every click along the bottom of the page. It used to be two controls sharing the bar: a fixed section well plus a `flex-1` rail with a "Sheets" heading, an inline name field, and a `+ New` button — 464px of the column held open for a list that is one item long for most people. Sheets carry the day's direction as a dot in the glyph slot so every cell stays the same shape. Section labels are the phone's short ones (Home, Pulse, Lab, Growth, Circle). Creating a portfolio is the `+` glyph cell, opening the same dialog the phone opens — never an inline field in the chrome. **Whether a cell exists may depend on your data, never on which page you are looking at** — the well is centred and content-sized, so one dropped cell resizes and re-centres the whole bar mid-navigation. `hideAdd` was wired to `!onBook` and did exactly that on the way to Circle; it is account-level now (`paperClassOnly`), and `src/lib/dock-stability.test.ts` fails if any width-determining prop is wired to a route check again. The same rule bit the phone bar in a quieter way: `MobileChrome` took `hiddenModeIds` as an optional prop and none of its four call sites passed it, so Account/Circle/Fund/Admin would have disagreed with the book the moment a tier hid anything. It derives the tier itself now (`useHiddenMetaTabIds`) so a new page cannot forget. Whether the sheets fold into one picker cell is decided by `dockFoldsSheets` (`src/lib/dock-cells.ts`) from **both** the cell count and the row's measured width; the seed household has four portfolios, so check any lowered cap against a real book. Full account and measurements in `DESIGN_TOKENS.md` ("The dock").
- **No empty leftover cells in hairline grids.** `gap-px` + `bg-border` paints every CSS grid track. Use `Segmented`, `HairlineGrid`, or `Scoreboard` so the column count always divides the children (`src/lib/filled-grid.ts`). Never hand-roll `grid-cols-N` on that pattern.
- **24-hour clock everywhere — never AM/PM.** Every time a person reads in the app is 24-hour: 08:30 and 20:30, not 8:30 AM / 8:30 PM. Format clock readings through `formatDateTime` (`src/lib/timezone.ts`), which pins `hourCycle: "h23"` so the browser's locale still picks date order and month names but never the hour style. Do not call `toLocaleString`/`toLocaleTimeString` directly for anything with an hour in it, and do not pass `hour12`. `hour: "2-digit"` over `hour: "numeric"` so times line up in `tabular-nums` columns.
- **Listing-currency chips only on mixed books.** `TickerSymbol` shows the USD/EUR/SEK chip only when `listingCurrenciesAreMixed` is true. USD-only and EUR-only books stay chip-free. Share price and average buy stay in the listing's own money; Cost / Value / gain follow the sheet USD/EUR toggle. Table rows never wrap. Mixed books left-align tickers and size that column to the cashtag+chip (`tableCols(n, true)`). Single-currency books keep centered equal columns. Every table row is a fixed `h-10`. Do not add `min-h` or extra vertical padding on cells.
- **Design system: see `DESIGN_TOKENS.md` for the full account.** True-black field (`--background`, `oklch(0 0 0)`), shadcn's own default card/popover step (`--card`, `oklch(0.205 0 0)` — do not darken this further, it already matches the sign-in page and shadcn's own dark-mode default), hairline borders (`--border`, white at 16% alpha, not a fill). Primary accent is a **subtle warm yellow** (`--primary`, `oklch(0.8 0.09 90)`) — muted and low-chroma on purpose, a quiet warm neutral rather than a bright brand color or the old loud/saturated gold ("Gold Delta"); the only other colors allowed are semantic and fixed: emerald `--gain`, rose `--loss`/`--destructive`, orange `--warning`. Don't reach for a new Tailwind hue decoratively — the Accent Palette in `DESIGN_TOKENS.md` is a ceiling, not a starting point; add to that file first if a fix seems to need a new color. Two typefaces split by job — Geist for every sentence, Geist Mono for every figure, **Archivo** for headings and the wordmark (`--font-heading` / `--font-logo`); heading tracking is a scale, not a constant (see `DESIGN_TOKENS.md` "Two typefaces"). Real shadcn primitives only (`Card`, `Table`, `Badge`, `Progress`, `Dialog`, `Select`) over hand-rolled divs; semantic tokens (`bg-card`, `border-border`, `text-muted-foreground`) over literal colors; the 4px/8px spacing scale over arbitrary `p-[13px]`-style values; `font-mono tabular-nums` on every dollar amount, percentage, and share count. No tinted/muddy card-background washes (`bg-<hue>-950/20` and similar) — status is a border accent or a `Badge`, never a fill. Top-level cards/panels use the `.glass` utility (translucent `bg-card` + backdrop blur) instead of an opaque fill, and nested wells use `.glass-well` — this is what lets the ambient corner glow read through card surfaces, not just in the gutters between them. Don't reintroduce a flat opaque `bg-card`/`bg-muted` on a top-level card; use `.glass`/`.glass-well` (see `BOX`/`CARD`/`SCORE_CELL` in `Panel.tsx` for the canonical usage). The ambient corner glow on `.page-frame` (`src/app/globals.css`) is shared by every signed-in page and the sign-in page itself — a warm `--primary` key light off the top-left plus a blue `--ambient-cool` counter-lobe off the bottom-right (hue 250, 160° from the accent and 88° clear of `--gain`), both small, dim, and sized in `vw`/`vh` so the diagonal read survives on a phone and roughly three quarters of the field stays true black. It follows the tokens above automatically. `--ambient-cool` is chrome-only and has no Tailwind utility; don't reach for it on a component (see `DESIGN_TOKENS.md` "Ambient counter-lobe").
- **The phone is its own room, not a narrow desktop — see `DESIGN_TOKENS.md` "The phone is its own room".** Below `md` the ambient lobes come *in* (130vw x 70vh) and *up* (60%/66%): the desktop pair is wider than a phone, so both lights reached the page middle and cancelled — the warm one washing over everything, the blue never reading as blue. Glass thins to 66% / wells to 74% so the corner light comes through the cards rather than only around them, and the edge stroke goes to full `--border` to pay for it. The page gutter, `PANEL_PAD`, `NESTED_PAD` and `SCORE_CELL` all step to 16px below `sm`, and figures to `text-xl`, because a flat 24px everywhere left a two-up score cell ~118px to set a 24px figure in. **Figures wrap, they never `whitespace-nowrap`** — that is how `23.0% a year` escaped its card. Put the unit in the sub-line, not in the figure, and pass `Scoreboard mobileCols={1}` for any row whose cells carry a sentence. `overscroll-behavior-y: none` on `html, body` is load-bearing: without it WebKit's bounce drags the sticky top bar down and slices the floating tab bar in half. **A size class on an `<h1>`-`<h4>` now works, and until 2026-08-22 it did not** — the element rules sat outside `@layer base`, and an un-layered rule beats every Tailwind utility whatever its specificity, so size, weight, leading and tracking named on a heading were all silently discarded (a circle's name arrived in the phone top bar at 24px/600 from `text-sm font-medium`). The block moved into `@layer base` and the 53 call sites whose classes that woke up were stripped in the same commit, so nothing re-rendered — verified by measuring all 214 headings across ten pages at two widths before and after. `src/lib/heading-scale.test.ts` fails if a heading grows a typography class that disagrees with the scale again; resizing one is a real change now, so make it on purpose or put the class on a child element the way `SheetPicker` does.
